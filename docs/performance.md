# 성능과 수명 검증

2026-10-27에 개발 기준 `092710f`와 Graph Viewer 1.2.2를 비교했습니다.
검사 실행 방법은 [개발 안내](development.md#성능과-종료-검사)에 있습니다.

## 측정 조건

| 항목 | 조건 |
|---|---|
| 운영체제 | Windows |
| CPU와 GPU | Ryzen AI MAX+ 395, Radeon 8060S |
| 브라우저 | Chromium 149.0.7827.55, headless, D3D11 |
| 뷰어 영역 | 1,200 × 800 CSS px |
| 처리 시간 | 준비 2회 후 5회 측정한 중앙값 |
| 프레임 간격 | 노드를 선택하고 흐름 애니메이션을 재생한 상태의 requestAnimationFrame 간격 90개 |
| 메모리 | 가비지 수집 후 JavaScript 힙, DOM 수와 이벤트 리스너 수 |

처리 시간은 렌더러 API의 동기 처리 시간입니다.
카메라 애니메이션의 전체 재생 시간이나 실제 Codex 탭을 여는 시간과는 다릅니다.

## 대규모 그래프

프레임 간격은 낮을수록 부드럽습니다.
같은 브라우저와 그래프 자료로 비교했습니다.

| 노드 / 연결 | 조건 | 이전 프레임 간격 | 1.2.2 프레임 간격 |
|---|---|---:|---:|
| 50 / 160 | 순환 없음 | 76.0 ms | 9.6 ms |
| 250 / 1,000 | 순환 없음 | 538.9 ms | 9.7 ms |
| 500 / 2,000 | 순환 없음 | 966.6 ms | 20.1 ms |
| 500 / 2,000 | 순환 포함 | 835.7 ms | 50.1 ms |
| 500 / 2,000 | 긴 설명 | 806.0 ms | 20.0 ms |

500개 노드와 2,000개 연결의 순환 없는 그래프에서는 다음과 같이 줄었습니다.

| 처리 | 이전 | 1.2.2 |
|---|---:|---:|
| 최초 구성 | 494.4 ms | 273.2 ms |
| 선택 변경 | 374.7 ms | 29.1 ms |
| 카메라 갱신 | 136.1 ms | 4.5 ms |
| 그래프 교체 | 508.7 ms | 155.4 ms |

최대 크기의 순환 그래프에는 약 50 ms의 프레임 비용이 남아 있습니다.
모든 그래프가 60 fps로 표시된다는 결과는 아닙니다.

## 메모리

- 500개 노드와 2,000개 연결의 뷰를 100회 생성하고 제거했습니다.
- 같은 MCP UI 문서를 30회 다시 열었습니다.
- 최대 크기 뷰 4개를 동시에 만든 뒤 제거했습니다.
- 10분 동안 노드 선택을 바꾸며 힙과 DOM 수를 측정했습니다.
- 서버에 조회 500회, JSON 갱신 100회와 Mermaid 갱신 30회를 요청했습니다.

100회 제거 뒤의 힙은 약 3.64 MiB에서 2.45 MiB로 줄었습니다.
제거한 그래프가 유지하던 DOM과 옵션 참조를 해제했습니다.
4개 뷰를 제거한 뒤에는 DOM 수가 112,510개에서 129개로 줄었습니다.

30회 재열기 중 활성 문서는 2개, 이벤트 리스너는 3,050개로 유지됐습니다.
10분 시험에서는 초기 준비 이후 힙이 약 5.2~7.4 MiB 범위에 있었고, DOM 수와 이벤트 수의 지속 증가는 관찰되지 않았습니다.
이 결과는 해당 시간과 입력 범위에서의 관찰입니다.
검사 기간을 넘어선 모든 메모리 누수의 부재를 보장하지는 않습니다.

PowerShell 실행기와 Codex 번들 Node 24.19.0에서도 같은 반복 요청을 확인했습니다.
JSON 그래프 등록 후 측정한 서버 RSS는 약 80.1 MiB에서 66.2 MiB로 줄었습니다.
Mermaid 실행 의존성을 별도 청크로 나누고 필요할 때 읽도록 바꿨습니다.

## 화면 동작

선택 노드의 효과와 본문 그래프의 흐름 애니메이션을 유지했습니다.
미니맵은 선택 노드와 연결 경로를 정적으로 표시합니다.
20% 미만으로 축소하면 작은 글자와 연결점을 생략하고, 확대하면 다시 표시합니다.

## 종료 범위

종료 시험은 독립된 시험용 호스트와 그 자식 프로세스를 대상으로 합니다.
아래 조건을 각각 10회 실행했고, 총 40회에서 서버와 실행기가 모두 종료됐습니다.

| 조건 | 결과 |
|---|---|
| 호스트 연결 해제 | 10회 통과 |
| 호스트 강제 종료 | 10회 통과 |
| 실행기 강제 종료 | 10회 통과 |
| 입력 연결을 유지한 채 부모 종료 | 10회 통과 |

부모 프로세스가 사라지면 서버가 1초 간격으로 확인하고 저장 작업을 정리한 뒤 종료합니다.
실제 Codex 앱의 전체 종료는 실행 중인 프로세스의 PID와 생성 시각을 저장하고, 앱을 종료한 뒤 별도로 대조해야 합니다.
